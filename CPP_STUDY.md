# C++ CTRNN CTF Study

This is the C++17 lineage of the three-neuron CTRNN capture-the-flag study. The Python lineage remains in the repository separately.

## Source Lineage

| Source | Experiment |
| --- | --- |
| `v4.cpp` | Standalone 1v1 pickup-and-return coevolution with terrain and `last_move_blocked`. |
| `v5_elo_4v4.cpp` | Standalone 4v4 world, ten-sensor controller, Elo league, Hall of Fame, checkpoints, and replay export. |
| `v5_red_scrimmage.cpp` | Red-only side-balanced 4v4 self-play rehabilitation. Reuses the V5 world by including `v5_elo_4v4.cpp` with its main function disabled. |
| `v5_red_blue_curriculum.cpp` | Graduated red-versus-blue curriculum. Reuses both the V5 world and red scrimmage machinery. |

The experiments deliberately retain a three-neuron CTRNN throughout. V4 genomes contain 36 floating-point parameters. V5 adds nearest-teammate observations and contains 45 parameters.

## Build

Run the build script from PowerShell:

```powershell
.\build_cpp_study.ps1
```

Equivalent commands:

```powershell
g++ -std=c++17 -O3 -DNDEBUG -Wall -Wextra -Wpedantic -static -static-libgcc -static-libstdc++ -o v4.exe v4.cpp
g++ -std=c++17 -O3 -DNDEBUG -Wall -Wextra -Wpedantic -static -static-libgcc -static-libstdc++ -o v5_elo_4v4.exe v5_elo_4v4.cpp
g++ -std=c++17 -O3 -DNDEBUG -Wall -Wextra -Wpedantic -static -static-libgcc -static-libstdc++ -o v5_red_scrimmage.exe v5_red_scrimmage.cpp
g++ -std=c++17 -O3 -DNDEBUG -Wall -Wextra -Wpedantic -static -static-libgcc -static-libstdc++ -o v5_red_blue_curriculum.exe v5_red_blue_curriculum.cpp
```

The code has no third-party runtime dependency. It contains minimal NumPy `.npy` float64 readers and writers for genome/checkpoint interchange.

## Main Design

- Continuous 40 x 40 coordinates over a 23 x 23 ASCII terrain map.
- Discrete actions: forward, backward, turn left, turn right, and no-op.
- Three recurrent sigmoid neurons with evolved recurrent weights, biases, time constants, and sensor weights.
- Dynamic objective: enemy flag while outbound, own home while carrying.
- Pickup requires proximity to the opposing flag; scoring requires carrying it home.
- First to three completed returns wins; otherwise the higher return count wins at 900 steps.
- Four randomized spawn assignments per color in V5.
- Ten V5 sensors: objective, nearest opponent, nearest teammate, and blocked movement.

## Launchers

The launchers record the configurations used for the major local studies:

- `run_v4_eventonly_8h.cmd`
- `run_v5_elo4v4_until_8pm.ps1`
- `run_v5_red_scrimmage_until_8pm.ps1`
- `run_v5_red_blue_curriculum_overnight.ps1`
- `run_v5_elo4v4_reentry_until_8pm.ps1`

They reference evolved `.npy` checkpoint files generated by earlier phases. Those large/generated artifacts are intentionally not part of this code commit.

For a source-only smoke test that does not require a checkpoint, V4 can start from random populations:

```powershell
.\v4.exe --quick --out-prefix v4_smoke
```

Use `--help` on `v4.exe` or `v5_elo_4v4.exe` for the supported training and replay arguments.
